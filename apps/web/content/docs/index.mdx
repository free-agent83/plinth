title: Plinth
description: A code-first design system where correct UI is the default output.
---

Plinth packages DTCG design tokens and React components so that the
right styling, accessibility, and behaviour are the **default output**. A
per-component review does not have to enforce them.

## What's here

- **Tokens**: a Clean Slate palette, an elevation scale, radius, and an Inter +
  JetBrains Mono type system, all rebindable per theme.
- **Components**: grouped by what they are for (actions, forms, display,
  navigation, overlays, layout), each documented with live, interactive previews
  on the next pages.

These docs are built from Plinth too: the same components and tokens they
describe.
